# MedicinIQ DICOM Connector — instalátory

Veřejné vydané verze konektoru MedicinIQ pro **Windows**, **macOS** a **Linux**.

Stahujte vždy poslední verzi v sekci [Releases](https://github.com/MediciniQ/dicom-connector-releases/releases/latest).
Licenční klíč a nápovědu k instalaci najdete v aplikaci MedicinIQ na stránce **DICOM Connector**.

Zdrojový kód tu není — repozitář slouží jen k distribuci podepsaných instalátorů.
